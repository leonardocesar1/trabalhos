Este repositório é um compilado dos meus Trabalhos Práticos (TPs) desenvolvidos durante a graduação, além de artigos acadêmicos desenvolvidos durante a Iniciação Científica. A ideia aqui é centralizar a minha evolução no curso e manter os códigos organizados.

**## O que você vai encontrar?**

**### Trabalhos Práticos (TPs)**
Implementações e projetos das principais disciplinas do curso, divididos por áreas:

* **Algoritmos e Estruturas de Dados:** `tp_algoritmos`, `tp_estrutura_de_dados`, `tp_pesquisa_operacional` e `tp_sistemas_lógicos`.
* **Hardware e Sistemas Distribuídos:** `tp_sistemas_operacionais`, `tp_organização_de_computadores` e `tp_sistemas_paralelos`.
* **Engenharia de Dados e Inteligência Artificial:** `tp_banco_de_dados`, `tp_desenvolvimento_de_software`, `tp_engenharia_de_software` e `tp_proteção_e_privacidade`.

**### Pesquisa e Artigos Acadêmicos**
Além dos códigos das disciplinas, o repositório conta com dois artigos focados em Machine Learning e resolução de entidades:

* **Severe Name Homonymy:** Um artigo completo que aborda a vinculação de entidades em registros civis sob alta ambiguidade de nomes. O trabalho utiliza uma abordagem de *Learning to Rank*. O estudo envolve modelos preditivos como LGBMRanker e XGBRanker, além de similaridade semântica baseada em BERT.

* **Close Social Relationship Classification:** Um artigo curto investigando se modelos de classificação de relacionamentos sociais conseguem generalizar através de diferentes bases de dados de comunicação. O trabalho analisa dados de interações mobile, como ligações e SMS, utilizando algoritmos como o LightGBM.
